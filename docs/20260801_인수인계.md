## 🛠️ 금일 작업 완료 및 반영 사항

### 1. 설정 화면 개편 및 '개발자 로컬테스트' 커스텀 IP 매핑
* **파일**: [frontend/index.html](file:///d:/12. Antigravity/20260731_PCoach/frontend/index.html), [frontend/js/app.js](file:///d:/12. Antigravity/20260731_PCoach/frontend/js/app.js)
* **수정 내용**:
  * 기존의 난해한 백엔드 URL 입력 폼과 라디오 버튼 옵션을 제거하여 일반 사용자에게 더욱 심플하게 다듬었습니다.
  * 설정 드로어 최하단에 **[개발자 로컬테스트]** 체크박스를 신설하여 체크 여부에 따라 하위의 **`로컬 서버 URL` 입력란**이 동적으로 토글(노출/숨김)되도록 구현했습니다.
  * **매핑 분기**:
    * **체크 ON & URL란 비어있음**: PC 테스트 기본값인 `http://127.0.0.1:8000`을 타겟팅합니다.
    * **체크 ON & 커스텀 IP 입력**: 사용자가 작성한 LAN 내부 PC 사설 IP(예: `http://192.168.0.59:8000` 등)가 저장 및 백엔드 URL로 지정됩니다.
    * **체크 OFF**: 웹 기본 동작 방식에 맞게 배포 도메인(`window.location.origin`)을 기반으로 백엔드를 자동 설정합니다.

### 2. 기기별(PC/Android/iOS) SQLite DB 경로 동적 분기 구현
* **파일**: [api/index.py](file:///d:/12. Antigravity/20260731_PCoach/api/index.py) (`get_db_path()`)
* **수정 내용**: SQLite DB인 `pronunciation_app.db`를 연결할 때 실행 환경의 OS를 자동으로 감지하여 저장 경로를 분기하도록 처리했습니다:
  * **Android**: `/storage/emulated/0` 디렉토리 감지 시, `Documents/VoiceTutor_Records/` 디렉토리에 생성.
  * **iOS**: 윈도우가 아니면서 앱 샌드박스 문서 폴더(`~/Documents`)가 감지되는 경우 해당 경로 하위에 생성.
  * **PC 및 Vercel**: PC 사용자의 홈 폴더 내 `VoiceTutor_Records/` 폴더 또는 Vercel의 `/tmp` 임시 폴더 하위에 생성.

### 4. DB 이력 'txt파일' 불러오기 전용 모드 지원
* **파일**: [frontend/index.html](file:///d:/12. Antigravity/20260731_PCoach/frontend/index.html), [frontend/js/app.js](file:///d:/12. Antigravity/20260731_PCoach/frontend/js/app.js)
* **수정 내용**:
  * 드로어 내 DB 이력 타이틀 우측에 **[txt파일]** 체크박스(디폴트: 해제)를 추가했습니다.
  * **체크 상태로 이력 카드 선택 시**: 상세 결과창 복원 과정을 거치지 않고, 해당 세션의 순수 본문 텍스트(`raw_text`)만 화면 뷰어 및 편집기에 이식하고 평가 점수판은 리셋하여 **해당 텍스트로 즉시 신규 녹음과 연습이 가능한 상태(연습 모드)**로 전환합니다.
  * **체크 해제 상태로 이력 카드 선택 시**: 기존 방식대로 점수 및 피드백, 구간 오디오 복원 등의 정적 결과 로드를 처리합니다.

### 5. 텍스트 직접 입력 시 임시파일명 제거 및 저장 누락 방지 검증
* **파일**: [frontend/js/app.js](file:///d:/12. Antigravity/20260731_PCoach/frontend/js/app.js)

    > *"⚠️ [파일저장 누락] 녹음을 시작하기 전에 먼저 본문 텍스트를 저장하여 파일명을 지정해 주세요."*
