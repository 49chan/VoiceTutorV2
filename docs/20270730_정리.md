## ⚠️ 설정 저장 실패(서버 오류: NOT_FOUND) 원인 분석

Vercel 실서버(`https://voicetutor-sand.vercel.app`)에서 "기본값(클라우드)"을 적용하고 설정 저장을 누를 때 `NOT_FOUND` 팝업이 뜨는 명확한 이유입니다:

1. **Vercel 설정 상의 Root Directory 문제**:
   * 현재 Vercel 프로젝트(`voicetutor.v2`) 대시보드 설정 상 **Root Directory가 `frontend`로 지정**되어 있습니다.
   * 이로 인해 루트의 `vercel.json` 설정과 루트에 위치한 파이썬 FastAPI 백엔드 코드(`api/index.py`)가 Vercel 배포 빌드 시 완전히 배제되어, Vercel 상에 백엔드 API 서버리스 기능들이 전혀 배포되지 못하는 상태입니다.
2. **현상**:
   * API 백엔드가 부재하므로 `/api/settings`에 대한 POST 요청 시 Vercel에서 404 NOT_FOUND를 반환하여 오류 경고창이 발생하게 됩니다.
   * 로컬 구동 시에는 파이썬 API 서버가 켜져 있어 정상 저장되나, Vercel 실서버 웹사이트 상에서는 배포 구조 불일치로 실패하는 것입니다.

## 🚀 내일 진행해야 할 후속 조치 방법

다음 세션을 시작할 때 다음 단계를 밟아 백엔드 배포를 정상화해야 설정 저장 오류가 영구 해결됩니다.

1. **Vercel 대시보드 Root Directory 수정**:
   * [Vercel](https://vercel.com/) 로그인 후 `voicetutor.v2` 프로젝트 클릭
   * **Settings** -> **General** 탭 진입
   * **Root Directory**에 설정되어 있는 `frontend` 텍스트를 제거하여 **빈칸(Repository Root)**으로 바꾼 뒤 저장(Save)합니다.
2. **루트 폴더에서 배포 재실행**:
   * 터미널을 열고 `frontend` 폴더가 아닌 **프로젝트 최상위 루트 폴더(`d:\12. Antigravity\20260724_KCoach_v2`)**에서 다음 명령어로 재배포합니다:
     ```powershell
     npx vercel --prod
     ```
   * 이렇게 배포하면 `vercel.json` 설정을 읽어 백엔드 API와 프론트엔드 빌드 아웃풋이 모두 정상 연결 배포됩니다.
