### 4. Supabase DB 신규 컬럼 매핑 추가
* **대상 파일**: [frontend/js/app.js](file:///f:/backup/12.%20Antigravity/20260731_PCoach/frontend/js/app.js)
* **내용**: `user_records` 테이블에 추가된 신규 평가 관련 컬럼에 데이터 적재 로직 반영
  * `feedback` 적재 시점에 맞춰 아래의 신규 컬럼 값을 객체 배열에 추가하여 Supabase에 삽입(insert)되도록 구현:
    * `audio_filename`: 평가 오디오 파일명 (`evalResult.audio_filename`)
    * `raw_text`: 낭독 원본 텍스트 (`evalResult.raw_text`)
    * `overall_score`: 종합 점수 (`evalResult.overall_score`)
    * `accuracy_score`: 정확도 점수 (`evalResult.accuracy_score`)
    * `fluency_score`: 유창성 점수 (`evalResult.fluency_score`)
    * `completeness_score`: 완성도 점수 (`evalResult.completeness_score`)
    * `evaluation_json`: 평가 결과 전체 JSON 객체 (`evalResult`)

### 5. 평가파일 불러오기 취득처를 Supabase로 변경
* **대상 파일**: [frontend/js/app.js](file:///f:/backup/12.%20Antigravity/20260731_PCoach/frontend/js/app.js)
* **내용**: '파일 불러오기' 화면의 평가 이력 조회 방식을 SQLite API 기반에서 Supabase의 `user_records` 테이블 조회 방식으로 변경
  * `loadDbHistory()`: 백엔드 `/api/db-history` API 호출 대신, `supabaseClient`를 사용하여 사용자 ID 기준의 `user_records` 테이블 데이터를 직접 쿼리하여 리스트 표출
  * `loadDbEvaluationDetail()`: 백엔드 개별 조회 API(`/api/db-history/{fileName}/{version}`) 호출 대신, 리스트 쿼리 결과에 캐싱된 객체 정보(및 `evaluation_json` 필드)를 다이렉트로 복원하여 로딩 성능 및 독립성 극대화

### 6. Vercel v2 도메인 로그인 시 기존 도메인 리다이렉트 현상 분석
* **내용**: `https://voicetutorv2.vercel.app/`에서 로그인 시 기존 도메인(`https://voicetutor-sand.vercel.app/`)으로 이동하는 오류 진단
  * **원인**: 프론트엔드는 현재 접속 origin 주소를 동적으로 보내고 있으나, Supabase 프로젝트 설정 내 **Site URL** 및 **Redirect URLs** 정보가 이전 도메인으로 고정되어 발생한 현상으로 진단
  * **해결 가이드**: Supabase 대시보드(Authentication -> URL Configuration)의 Site URL을 `https://voicetutorv2.vercel.app`로 수정하고 Redirect URLs에 `https://voicetutorv2.vercel.app/auth/callback` 추가 조치 권고
