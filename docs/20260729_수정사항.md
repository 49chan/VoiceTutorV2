1회차 -------------  

1. 설정
  - 화면테마를 블랙/화이트로 선택가능하게 하고 그 선택에 따른 화면의 바탕색을 변경한다.
  
2. 변환
  - 파일열기에서 이미 기능이 있으므로 별도로 [변환]버튼은 필요없음.
 
3. 녹음
  - 평가 후는 [녹음]보턴을 비활성한다.
  - 녹음 시 우측하단에 표시되는 타이머는 우측상단의 플레이아이콘의 왼쪽에 노출한다.
  
4. 평가
  - 평가 후 결과가 표시된 이후에는  [평가]버튼을 비활성화 한다.
  - 평가의 피드백 리포트과 점수는 화면의 상단에 노출하도록 수정한다.

2회차 -------------  

1. 파일열기
  - json 파일을 열었을 때는 연필아이콘의 편집기능은 비활성화 한다.
  - json 문장의 길이나 행수에 따라 스크롤기능을 활성화 한다. 
    활성화 되지 않으니 하단의 설정이나 종료버튼이 보이지 않는다. 다른 대안이 있으면 알려줘
  - json의 점수는 바탕색이 화이트인 경우 점수가 눈에 띄지 않는다.
