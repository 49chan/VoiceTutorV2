
1. 로그인(phase.3) - 버튼비활성화
	- 이메일
	- 만족도 평점 입력

2. 게시판(phase.3) - 버튼비활성화
	- 사용자 만족도 평점 표시리스트 (사용자ID/평점/한줄소감)
	
3. 초기화면
	- 한줄소개: 나만의 문서가 실시간 원어민 튜터가 되다.
	- 이미지
	
4. 파일열기(.txt or .json)
	- 파일을 업로드한다.
	- .txt인 경우 신규로 판단 녹음과정으로 대기
	- .json인 경우 평가내용 노출
	
5. 추출(or 변환)(.pdf)
	- 파일을 업로드하고 추출하고자 하는 페이지를 입력한다.
	- 지정한 페이지의 문자데이터만을 취득한다.
	- 취득한 문자를 화면에 출력한다. 취득해서 출력된 내용이 틀린 경우 수작업으로 수정가능하다.
	- 편집 후 저장기능도 있어여 함

6. 녹음
	- 중지버튼에 의해 녹음파일 저장됨
	- 녹음진행 후 2분이 되면 자동정지되고 녹음파일 정장됨
	
7. 평가
	- 문장 텍스트 부분에 상, 중, 하로 평가내용을 색으로 화면에 출력한다.
	- 발음평가한 내용을 출력하고 평가점수도 화면에 출력한다.
	- 평가한 [파일명 / 회차 / 평가점수 / 일시 / 평가내용] 을 행(Row)을 지정된 구글 시트에 자동 추가 (별도 조회 화면 불필요).
	
8. 설정
	- 마이크 사용여부
	- API Key 관리
	- 추출파일(.txt), 평가파일(.json), 녹음파일(.mp3)의 저장경로 지정
	- 평가내용 구글시트 저장경로 지정
